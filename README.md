# Phone-Price-Prediction-in-Indian-Markets-using-Linear-Regression

– Performed EDA on the dataset with 18 features to gain insights into the predictors affecting response variables
– Applied Multiple Linear Regression with necessary variable transformations, one‐hot encoding and improved
model by addressing outliers, heteroscedasticity using the Goldfeld‐Quandt Test and multicollinearity with VIF
– Attained an Adj. R2
value of 0.78 for the final model applied to the test data, accompanied by a test MSE of 0.24
